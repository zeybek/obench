# Security

Please report security problems privately through GitHub's private vulnerability reporting (the "Report a vulnerability" button on the Security tab), not in a public issue. You'll get a first reply within 14 days.

Before 1.0, only the latest release gets fixes, including security fixes, so upgrade to it to get them. [SUPPORT.md](SUPPORT.md) lists the supported Odin versions.

The obench CLI builds and runs the Odin packages it finds under the directory you point it at, the same way `odin run` would. Don't run it on code you don't trust.
